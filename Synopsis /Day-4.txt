#Promises:


function getData() {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve("Data received");
        }, 2000);
    });
}




#setTimeout

We can set the time at which we want to run or console something.

setTimeout(()=>{
    console.log("Hello");
},2000);




#setInterval

Same as setTimeout but the same data is printed or logged again and again in a particular time interval given.

setInterval(()=>{
    console.log("Data checking again and again");
},5000);
