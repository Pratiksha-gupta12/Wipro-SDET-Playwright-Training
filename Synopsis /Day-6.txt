// Ques-2
E-Commerce Discount Applicator


#Steps:

1- Accepted an array of product objects having data :
    product name
    price
    category

2- Created a callback function isEligible().
3- Check whether:
    product category is "Electronics"
    product price is greater than $200

4- Used map() to iterate through all products
5- Calculated a 10% discount for eligible products and updated product prices.
6- Added a new property called isDiscounted:
      true -> discounted products
      false -> non-discounted products

7- Calculated: Savings and total discounted items
8- Used setTimeout() to simulate delayed.
9- Displayed the updated cart.




#Code Snippet
if (isEligible(product)) {

    let discount = product.price * 0.10;

    totalSavings += discount;
    discountedItems++;

    return {
        name: product.name,
        price: product.price - discount,
        category: product.category,
        isDiscounted: true
    };
}
